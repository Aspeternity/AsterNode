# 兼容性状态

## 管理器目标矩阵

开发规格声明的首版目标为：

| 系统 | 架构 | 当前证据 |
|---|---|---|
| Debian 12 | x86_64 / ARM64 | 仅 Stage-A fixture/逻辑测试；未完成真实部署矩阵 |
| Debian 13 | x86_64 / ARM64 | 当前开发容器为 Debian 13 x86_64，但无 systemd；不能替代真实 VPS |
| Ubuntu 22.04 | x86_64 / ARM64 | 未实测 |
| Ubuntu 24.04 | x86_64 / ARM64 | 未实测 |

网络目标：IPv4、双栈、IPv6-only。当前 Stage A 只实现检测模型，没有对这些网络形态给出最终支持结论。

## Xray / 导出 profile

`compat/compatibility.json` 中存在开发期固定核心与 profile 元数据。它用于后续阶段 B 的实现输入，不代表 T24/T25 已通过。真实 3x-ui 面板版本、线路端 Xray 版本和实际出口验证仍为空缺。

## 版本声明原则

- 未实测组合不得标记为“支持已验证”。
- 预发布版本不能作为默认更新目标。
- 核心字段与导出 profile 必须与具体版本绑定，不把某一版本字段外推到全部历史版本。
